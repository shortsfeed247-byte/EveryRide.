# **App Name**: AetherGo

## Core Features:

- Secure Account & Identity: User Login/Signup with OTP and Google. Driver onboarding with robust KYC verification and document submission (DL, RC, Aadhaar).
- Dynamic Ride Creation & Booking: For users: intuitively input pickup/drop locations, select vehicle type (Bike, Auto, Cab), view real-time price estimations, and confirm ride bookings. For drivers: receive and accept/reject incoming ride requests.
- Real-time Matching & Interaction: Seamlessly match users with nearby available drivers. Display driver details, vehicle information, and live map tracking. In-app call and chat options for direct communication.
- AI-Powered Predictive Tool: An AI tool providing drivers with a heatmap of high-demand areas to optimize their routes and earning potential. Suggests optimal next ride locations.
- Seamless Transactions & Payouts: For users: integrated payment options including UPI, in-app Wallet, and Cash. For drivers: manage daily/weekly/monthly earnings, track incentives/bonuses, and facilitate secure wallet withdrawals.
- Personalized Dashboards & History: For users: access detailed ride history, manage saved locations, and view profile information. For drivers: an intuitive dashboard displaying online/offline toggle, today's earnings, total rides, and uploaded documents.
- Adaptive User Experience & Support: Toggle between Dark Mode and Light Mode, navigate with smooth transitions, receive real-time notifications, and access universal settings (language, help, support, safety features like SOS button).

## Style Guidelines:

- Overall color scheme: Dark, providing a premium and futuristic aesthetic.
- Primary color: A vibrant, electric purplish-blue (#6B1AFF) for key interactions and prominent elements, reflecting energy and modernity. Converts from HSL(245, 90%, 65%).
- Background color: A very dark, subtle purplish-grey (#1F1C29), visibly derived from the primary hue, but heavily desaturated to provide a deep and clean base. Converts from HSL(245, 20%, 15%).
- Accent color: A striking electric cyan (#1FC7FF) for highlights, calls-to-action, and to create strong visual contrast, chosen as an analogous color to the primary. Converts from HSL(215, 95%, 70%).
- Headlines and prominent text: 'Space Grotesk' (sans-serif) for a modern, tech-inspired, and slightly futuristic look.
- Body text: 'Inter' (sans-serif) for its highly legible, objective, and contemporary aesthetic, ensuring comfort in reading longer texts like ride details and notifications.
- Modern, sleek Material UI style icons with clean lines and rounded forms to align with the futuristic, premium theme. Utilizes glowing effects on active states to emphasize the neon aspect.
- A unique card-based layout, utilizing glassmorphism effects and rounded corners for a premium feel. Features floating action buttons and ensures clean spacing and alignment throughout for optimal readability and a modern, minimalist look.
- Smooth, fluid animated transitions between screens, subtly animated buttons on interaction, and dynamic real-time notification UIs to enhance the futuristic and responsive user experience.
